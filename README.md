# 💪 100 Pompes — Challenge 30 Jours

Site de suivi du challenge 100 pompes/jour pendant 30 jours (1er → 30 avril).

## Fichiers

```
index.html   → Structure de la page
style.css    → Design & mise en page
data.js      → Programme des pompes (chargé avant app.js)
app.js       → Toute la logique (timer, localStorage, graphique)
```

## Déploiement sur GitHub Pages

1. Crée un repo GitHub (ex: `pushup-challenge`)
1. Upload les 4 fichiers à la racine
1. Va dans **Settings → Pages → Source → main branch → / (root)**
1. Ton site sera dispo sur `https://[ton-pseudo].github.io/pushup-challenge`

## Données

Tout est sauvegardé dans le **localStorage** du navigateur.  
Les données restent tant que tu ne vides pas le cache du navigateur.

> ⚠️ Si tu utilises le site sur plusieurs appareils, les données ne se synchronisent pas entre eux.
